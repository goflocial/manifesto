# The Flocial Manifesto

What online community can be: networks that measure their success by whether their members flourish, not by
how much of their attention they hold.

| Document | What it is |
|---|---|
| [MANIFESTO.md](MANIFESTO.md) | The manifesto: 22 principles in seven pillars, and the values beneath them |
| [EVIDENCE.md](EVIDENCE.md) | The appendix: every source behind every claim, each labelled by strength |
| [FRAMEWORK.md](FRAMEWORK.md) | For builders: patterns, anti-patterns, measures and a 22-question self-assessment |
| [RUBRIC.md](RUBRIC.md) | An optional module for rating outside organizations a network brings in |
| [COMMUNITY-CHARTER.md](COMMUNITY-CHARTER.md) | A charter any community can write |
| [CHANGES.md](CHANGES.md) | Every substantive change, draft by draft |

Read it, and sign it, at https://flocialmanifesto.org.

## Propose a change

This is a draft, and it changes in public. Open an issue to question a claim, point out a weak source or
suggest a principle; or open a pull request with a proposed edit. Every claim needs a source in EVIDENCE.md,
and every change is recorded in CHANGES.md.
